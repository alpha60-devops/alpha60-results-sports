Payload size is taken from the original torrent metainfo, excludes padding, and uses decimal GB. It describes advertised payload, not observed transferred bytes. Resolution, duration and file count confound language-pack size.

1. **Most classified torrents are monolingual:** 323 of 335 (96.4%). Only 12 contain two or more identified audio languages.
2. **Multilingual does not necessarily mean multiple files.** Median media-file count is 1.0 in each classified language-count group; additional tracks can be packaged in one container.
3. **The biggest packages are a coverage problem.** The unclassified-language group reaches 487.91 GB. A short probe of one file cannot describe a package of many matches.
4. **English subtitles are concentrated:** 47 of the 50 subtitle-classified torrents contain English. This is a property of the sampled supply, not a measure of viewer accessibility needs.
